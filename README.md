Ember Yard is a round-based tactical FPS in three.js: plant or defuse the bomb across two sites in a dusk industrial yard, buy rifles, SMGs and grenades between rounds, and outplay bots that patrol lanes, hold sites and react to what they see and hear.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
